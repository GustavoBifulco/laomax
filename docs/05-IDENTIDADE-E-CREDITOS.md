# Identidade e créditos

## Selo da LAOMAX

- Arquivo fornecido pelo usuário: `Selo Acadêmico LAOMAX em Mandíbula Gravada.png`.
- Cópia preservada: `assets/images/laomax-selo-original.png`.
- Cópia dimensionada para o site: `assets/images/laomax-selo.png`, com 900 pixels de lado.
- Favicon: `assets/images/favicon.png`.
- O desenho não foi redesenhado, vetorizado ou alterado. Foram criadas cópias dimensionadas; a apresentação circular é feita por CSS.
- O hash do original está registrado em `assets/manifest.json` e é conferido por `npm run check`.

## Paleta

| Uso | Cor |
| --- | --- |
| Fundo principal | `#f5f2eb` |
| Fundo secundário | `#eae6dc` |
| Texto principal | `#1b1d18` |
| Texto secundário | `#64665e` |
| Laranja principal, baseado no selo | `#e85a00` |
| Laranja para títulos sobre fundos claros | `#e25700` |
| Laranja para textos pequenos e links | `#b83e08` |
| Linhas | `#d5d3c9` |

O laranja principal foi escolhido a partir dos tons amostrados no arquivo do novo selo; a imagem contém variações e não foi fornecido um manual com um único código oficial. O tom mais escuro é aplicado a textos pequenos e links para favorecer o contraste. A faixa de participação e a capa laranja usam o tom vivo da marca com texto escuro.
